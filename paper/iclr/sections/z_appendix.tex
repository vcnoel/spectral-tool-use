\section{Proofs}
\label{app:proofs}

\begin{proof}[Proof of Proposition~\ref{prop:annihilation}]
The first claim is immediate, since $\Phi$ factors through $\bar W$. For the second, note first which
symmetric graphs Eq.~\ref{eq:adj} can produce from a causal head. Since $(A_h)_{ij}=0$ for $j>i$, the
off-diagonal entries are $W_{ij}=\tfrac12(A_h)_{ij}$ for $i>j$, so a symmetric zero-diagonal $W$ is realisable
exactly when every node sends total weight at most $\tfrac12$ to the nodes before it, $2\sum_{j<i}W_{ij}\le 1$
for all $i$: set $(A_h)_{ij}=2W_{ij}$ for $i>j$ and put the remaining mass on the diagonal. The condition is
convex, so a mean of realisable graphs is realisable. Take $T\ge 3$, let $P$ be the path graph on $T$ nodes
with weights $\tfrac12$, in which every node attends fully to its predecessor, and let $K$ be the complete
graph with weights $1/(2(T-1))$; both satisfy the condition. Put $W_1=P$, $W_2=K$ and
$W_1'=W_2'=\tfrac12(P+K)$, and for $H>2$ repeat the pattern. Both configurations have mean $\tfrac12(P+K)$.
The path has $\lamtwo(L_P)=1-\cos(\pi/T)=\Theta(T^{-2})$ while the complete graph has
$\lamtwo(L_K)=T/(2(T-1))>\tfrac12$, so the per-head vectors differ in their maximum by more than
$\tfrac12-\Theta(T^{-2})$, whereas every head-averaged functional returns the same value on both.
\end{proof}

\begin{proof}[Proof of Proposition~\ref{prop:jensen}]
The Laplacian is linear in the adjacency, so $\bar L=\frac1H\sum_h L_h$. Since $L_h\mathbf{1}=0$ and
$L_h\succeq 0$, Courant--Fischer gives $\lamtwo(L)=\min_{x\perp\mathbf{1},\,\|x\|=1}x^{\top}Lx$, a pointwise
minimum of functions linear in $L$, hence concave on the convex cone of graph Laplacians, and Jensen's
inequality applied to the uniform average over heads gives Eq.~\ref{eq:jensen}. For the equality case let
$x^\star$ attain the minimum for $\bar L$. Then
$\lamtwo(\bar L)=\frac1H\sum_h(x^\star)^{\top}L_hx^\star\ge\frac1H\sum_h\lamtwo(L_h)$, tight exactly when
$(x^\star)^{\top}L_hx^\star=\lamtwo(L_h)$ for every $h$, that is, when $x^\star$ is a Fiedler vector of every
head; conversely a common Fiedler vector $x$ gives $\lamtwo(\bar L)\le x^\top\bar L x=\frac1H\sum_h\lamtwo(L_h)$.
\end{proof}

\begin{lemma}[bounded spectrum]
\label{lem:bounded}
For any weighted graph with non-negative weights and no isolated vertices,
$\operatorname{spec}(\mathcal{L})\subset[0,2]$, with $\lammax=2$ if and only if a connected component is
bipartite; the bound is independent of the number of nodes.
\end{lemma}
\begin{proof}
Standard \citep{chung1997spectral}: for $x\ne 0$ and $y=D^{-1/2}x$, the Rayleigh quotient
$x^\top\mathcal{L}x/x^\top x$ has numerator $\sum_{i<j}W_{ij}(y_i-y_j)^2\le 2\sum_{i<j}W_{ij}(y_i^2+y_j^2)=2x^\top x$,
with equality only in the bipartite case.
\end{proof}

\section{Validity defects found in our own pipeline}
\label{app:validity}

Every defect below was present in a working pipeline, produced a plausible number, and was found only because
a confound baseline or a failure-mode count disagreed with it. The class is systematic in internal-state
detection work, where nothing external checks the measurement chain.

\begin{enumerate}[topsep=2pt,itemsep=2pt,leftmargin=1.4em]
\item \textbf{The chat template silently dropped the tools.} One family's template ignores the argument that
carries tool schemas; the model answered in prose and all \nGemmaDiscardedRecords{} extracted examples were
labelled \texttt{no\_call}, a hallucination rate of 100\% that was a property of prompt rendering.
\emph{Guard:} the renderer asserts every tool name appears in the rendered prompt, falls back to an explicit
system-prompt specification, and refuses to emit an example otherwise.
\item \textbf{A reasoning model spent its budget before calling.} A template defaulting to chain-of-thought
emitted long reasoning before any call, so within a fixed budget the call was often never reached; a
classifier on generation length alone scored \aucLengthConfoundQwenDenseBfclAll{}. \emph{Guard:} disable
thinking mode where the template supports it, and treat any run whose floor approaches its detectors as
uninterpretable.
\item \textbf{The labeller punished the model for knowing the date.} Ground-truth calls in a corpus written
earlier contain arguments such as \texttt{current\_date}. \emph{Guard:} arguments encoding the corpus author's
present are excluded from the comparison, with an alias table for interchangeable encodings.
\item \textbf{Hidden states entered the ``attention-only'' features.} In the library prior spectral work was
built on, four of five nominally spectral metrics project residual states onto the attention eigenbasis.
\emph{Guard:} every metric is tagged with its tensors and the attention tier admits only functions of the
attention weights (Appendix~\ref{app:provenance}).
\item \textbf{Probe checkpoints collided.} The trainer wrote its early-stopping checkpoint to a fixed path,
so concurrent trainings overwrote each other, silently with matching dimensions. \emph{Guard:} the best state
is held in memory.
\item \textbf{Repeated prompts were extracted twice}, 13\% of each Glaive dump, up-weighting them though
never crossing a split. \emph{Guard:} deduplicate at write and load time.
\item \textbf{Task identity leaked through prompt-level splits.} Errors concentrate on particular tools, so
with prompt-grouped splits a classifier on the tool identity reaches \aucToolConfoundLlamaOneBGlaiveAll{}.
\emph{Guard:} group splits by tool and keep the tool-identity classifier in the confound panel.
\item \textbf{A third call format went unparsed}, and \textbf{decoding deleted structural tags}: one family
writes \texttt{<function name="f"><param name="k">v</param></function>} and tokenises the tags as special
tokens, so a parser that knew two dialects and a decoder that skipped specials both scored every call as
absent. \emph{Guard:} three dialects parsed, specials kept and only chat control markers removed, and the
label distribution of a new model inspected before use.
\item \textbf{The truncation flag was wrong for a whole family}, reading ``truncated'' for $97.8\%$ of one
split because Llama closes a call with a marker other than end-of-sequence. \emph{Guard:} truncation is the
generated length against the budget.
\item \textbf{Our own budget was charged to the model.} \emph{Guard:} calls cut off by the budget carry a
distinct mode and are excluded from the semantic subset.
\item \textbf{A massive activation overflowed half precision} in one dimension of two thousand and was stored
as infinity. \emph{Guard:} single precision for stored states and a finiteness check at load.
\item \textbf{Confidence was summarised one way.} The mean of the five least likely tokens scores ten points
higher than the mean log-probability on the family where confidence loses. \emph{Guard:} nine summaries are
recorded and each scored as its own detector (Appendix~\ref{app:confvariants}).
\item \textbf{Arguments the schema does not define were not penalised}, whereas the benchmark's checker
rejects them. \emph{Guard:} a strict rule counts them as a distinct mode; on the stored single-turn runs it
changes at most \extraFlipsMaxPct{}\% of labels (\extraFlipsMaxRun{}), so those tables report the lenient
labels, and the multi-turn runs, where a weak model echoes schemas into argument-less calls, use the strict
one.
\item \textbf{Comparisons were read off seed spreads.} An earlier version placed seed standard deviations side
by side and read orderings off them; seed spread is not the uncertainty of a difference between detectors
scored on the same items. \emph{Guard:} a paired bootstrap over items on every reported difference
(Appendix~\ref{app:stats}).
\item \textbf{A control that pooled below chance was read as anti-predictive.} Under tool-grouped folds the
tool-identity classifier pools at 0.28--0.50 AUC. Its per-fold prediction is a constant, the training base
rate, which is anti-correlated with the held-out fold's rate, so the pooled AUC measures fold composition
and nothing else. \emph{Guard:} the mean of within-fold AUCs and the pooled AUC of the per-fold-constant
predictor are reported beside every pooled score (Appendix~\ref{app:stats}).
\item \textbf{An underpowered run was reported as data.} One run has \minClassPerSubset{} or fewer positives
on its evaluated population and spreads across seeds wider than the effects discussed. \emph{Guard:} a
minority-class floor gates every table; \nUnderpoweredRuns{} run carries a dagger.
\item \textbf{Two extractions of one model and benchmark were both counted}, and differed. \emph{Guard:} each
pair is counted once and the drift between extractions is reported as a replication bound
(Appendix~\ref{app:stats}); extraction now uses deterministic kernels and a pinned template date.
\end{enumerate}

Most of these inflate a result rather than deflate one. A detection number in this area should not be
believed without a confound panel evaluated under the same protocol and a stratification of labels by
failure mode.

\section{Protocol details}
\label{app:protocol}

\paragraph{Generation.} Greedy decoding, budget 256 new tokens (160 on the multi-turn runs), tool schemas
passed through the model's own chat template, bfloat16, deterministic CUDA kernels, seeded, chat-template date
pinned; every dump records library versions, hardware and commit.

\paragraph{Multi-turn.} The four multi-turn categories of BFCL-v4, one record per conversation turn up to the
fourth, with the ground-truth calls of the two preceding turns rendered as assistant messages each followed by
a fixed acknowledgement of success. Conversations with more than 22 tools are skipped. In the cascade
condition one preceding turn carries a call from another conversation with the same acknowledgement.
Attention is reduced to its features inside a forward hook on each attention module so a layer's
probabilities are released before the next layer computes; full-sequence graph features, cubic in the prompt
length, are not computed on these runs. Labels use the strict rule on undefined arguments.

\paragraph{Layers, heads and probes.} Residual probes read eight depths spaced by \texttt{linspace} over the
layer count; per-head features use every attentive layer. Logistic regression is $\ell_2$-regularised,
class-balanced, $C\in\{0.01,0.1,1,10\}$ chosen on validation; the token-role network has one hidden layer of
512 units, dropout 0.1, AdamW with warm restarts and early stopping. Gradient-boosted trees with a fallback to
logistic regression, decided on training folds, are used for the head-averaged per-layer sets.

\paragraph{Pooled cross-fit scores.}
Every AUC pools the out-of-fold scores of five classifiers, one per fold, each calibrated on its own training
tools. Two consequences follow. First, a deployed judge is one classifier with one calibration, so pooling
penalises calibration drift a deployment never sees: scoring the residual probe within folds gives
\poolWithinHiddenLlamaOneBGlaive{} on Llama-1B on Glaive against \poolPooledHiddenLlamaOneBGlaive{} pooled, a
cost of \poolCostHiddenMean{} AUC averaged over \poolNRuns{} runs, and the effect is far larger for a score
meaningful only relative to its fold, such as a rank (\poolWithinRankMeanLlamaOneBGlaive{} within folds against
\poolPooledRankMeanLlamaOneBGlaive{} pooled), which is why combinations are read within folds. Second, the
direction of the pooling effect is not fixed. Under tool-grouped folds the training base rate of each fold is
anti-correlated with the base rate of the tools held out from it, so a predictor that is constant within
each fold pools below chance; the tool-identity control, whose per-fold prediction is exactly such a
constant, pools at \foldOffsetToolOneHotBaseLlamaOneBGlaive{} on Llama-1B on Glaive with a within-fold AUC of
one half. Every pooled score in this paper is therefore accompanied in the result files by the mean of
within-fold AUCs (\aucFmHiddenLRBaseLlamaOneBGlaiveSem{} for the residual probe on that run) and by the pooled
AUC of its per-fold-constant predictor, and rows below one half are not inverted: for untrained scores whose
sign is fixed on training folds, a sign that flips between folds makes the pooled AUC uninterpretable and the
within-fold value is the one to read.

\section{Confidence summaries}
\label{app:confvariants}
\label{sec:exp:confvariants}

Comparing a trained judge against ``output confidence'' presumes a summary of the output distribution. We
record \CvLlamaBfclNSummaries{} per call, covering the mean, minimum, total and mean-lowest-five
log-probability, perplexity, the fraction of low-probability tokens, and the mean, maximum and final predictive
entropy, each scored as its own detector with its direction fixed on training folds. On Llama-3.2-1B on BFCL
the mean log-probability reaches \CvLlamaBfclMeanLp{} while the mean of the five least likely tokens reaches
\CvLlamaBfclBest{}: a single improbable token carries the evidence and averaging dilutes it, so the probe's
advantage falls from \CvLlamaBfclGapMean{} to \CvLlamaBfclGapBest{} without disappearing against the probe's
\CvLlamaBfclProbe{}. The total log-probability scores \CvLlamaBfclSumLp{}, close to the \CvLlamaBfclSurface{}
of the length floor, and is set aside as a length feature. On MiniCPM5-2B the best summary reaches
\CvMiniCpmBfclBest{} against \CvMiniCpmBfclMeanLp{}, the probe's deficit moves from \CvMiniCpmBfclGapMean{} to
\CvMiniCpmBfclGapBest{}, and the summaries fall within a couple of points of one another where on Llama they
range over seventeen: on one family the model's expressions of uncertainty agree with each other and with its
errors, on the other they do neither. The cross-run comparison of Section~\ref{sec:exp:budget} uses the mean
log-probability and therefore understates confidence on the families where it loses; the separation between
families survives the fairer comparison but is smaller than the mean alone suggests.

\section{Combining the two judges}
\label{app:combining}

Stacking the residual and attention scores with a combiner fitted on out-of-fold training scores, which
gives the combiner several times more labelled failures than a validation fold, changes AUC by
\agrStackGain{} and improves on the better single judge in \agrStackPositive{} of \agrNRuns{} runs; mapping
each score through the empirical distribution of its out-of-fold training scores first changes AUC by
\agrStackRankGain{} and helps in \agrStackRankPositive{} runs, with a best case of \agrStackRankGainMax{}, and
every fitted combiner gave both judges positive weight. Within folds the average of the two judges reaches

changes precision by \agrMatchedGain{} and helps in \agrMatchedPositive{} of \agrNRuns{} runs.

\section{Architecture, abstention and confounds}
\label{app:arch}
\label{sec:exp:arch}
\label{sec:exp:confound}
\label{app:confound}

On the sliding-window model, with four heads, one key-value head and local attention in all but four layers,
the per-head profile reaches \aucPerHeadAllGemmaGlaiveSem{} against a floor of
\aucSurfaceConfoundGemmaGlaiveSem{}, so a narrow, sparse attention stack does not disable spectral detection.
The hybrid families, in which only a quarter of the layers carry softmax attention, are where the tier
weakens, to the neighbourhood of the residual probes rather than below the floor.

The clearest architectural effect is about the models. On the category where no tool applies, the two Llama
models fabricate a call almost every time, \modeLlamaOneBBfclOvertrigger{} of \nIrrelevanceItems{} items at
1B and \modeLlamaThreeBBfclOvertrigger{} at 3B, while every other family abstains most of the time at every
size: Qwen3-1.7B on \modeQwenDenseBfclValidnocall{} items, Qwen3.5-4B on \modeQwenFourBBfclValidnocall{},
MiniCPM5-2B on \modeMiniCpmBfclValidnocall{} and Qwen3.5-0.8B on \modeQwenSmallBfclValidnocall{}. Abstention is
a property of the training recipe and not of scale; for a family that does not abstain, the capability has to
be supplied from outside the model.

The floor is not always low: on Llama-1B on BFCL a classifier on lengths alone reaches
\aucSurfaceConfoundLlamaOneBBfclAll{} on the full set, because format failures are long, and falls to
\aucSurfaceConfoundLlamaOneBBfclCall{} on the call-expected items while the detectors hold. Transfer separates
a detector that learned routing from one that learned a corpus: trained on Glaive and applied unchanged to
BFCL on Llama-3B, the residual probe retains \transferHiddenLRLlamaThreeBGlaiveToLlamaThreeBBfcl{} and the
per-head profile \transferPerHeadAllLlamaThreeBGlaiveToLlamaThreeBBfcl{} against in-domain values of
\aucHiddenLRLlamaThreeBBfclSem{} and \aucPerHeadAllLlamaThreeBBfclSem{}, while the length floor falls to
\transferSurfaceConfoundLlamaThreeBGlaiveToLlamaThreeBBfcl{}.
